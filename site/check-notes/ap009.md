## What it finds

Four kinds of thing in a package you are about to publish, with one print per kind and an example
path:

- Source maps that hold your original source (a `.map` file, or an inline map at the end of a
  `.js`, `.mjs` or `.cjs` file): the full code, comments included.
- Source maps without the source: your file layout and original names, enough to de-minify.
- Original source next to the compiled output (`.ts`, `.tsx`, `.mts`, `.cts`, `.vue`, `.svelte`;
  never `.d.ts`).
- AI instruction files (`CLAUDE.md`, `AGENTS.md`, `GEMINI.md`, `.cursorrules`, `.windsurfrules`,
  `.github/copilot-instructions.md`, `.cursor/rules/*`): a written tour of your codebase.

Severity depends on your licence. For a closed-source package, maps with source are high and the
other kinds are medium. For an open-source package, only maps with source are mentioned, as low.
The print never shows file contents.

## Why it matters

Nobody can stop people reverse engineering code you ship, and AI makes it faster. This check does
not claim to prevent it. It shows what in your package hands an AI your original source, or a map
of it, so the giveaways that were not on purpose can come out before you publish.

## How to fix

- Turn off the maps, or the source inside them, in your build: tsc `"sourceMap": false` or
  `"inlineSources": false`; esbuild `--sources-content=false`; Vite `build.sourcemap: false`;
  webpack `devtool: false`; Rollup `output.sourcemap: false`.
- Or keep the files out of the package with `.npmignore` or the `files` list in `package.json`
  (for Python, your build tool's exclude list). Keep `src/` and AI instruction files out too.
- Decide whether the package is meant to be open source. If it is, add a licence (an SPDX id such
  as `MIT`) and the medium and high prints go away.

`agentprint fix` lists this under "Needs you". It never edits your build settings.

## Limits

- Files are read within the `pack` limits: 10 MB each and 64 MB per package. A bundle over the
  limit is not checked for an inline map. A `.map` file over the limit still counts by its name.
  The print says how many files were not read.
- "Original source" is only flagged when compiled JavaScript ships too. A package that is only
  source is the product itself.
- Minified or obfuscated code without maps can still be reverse engineered by an AI. This check
  does not say otherwise.
- The licence rule decides closed or open. Closed means: no licence found, or unreadable; npm
  `UNLICENSED`, `SEE LICENSE IN ...`, `proprietary`, `commercial`, or any `LicenseRef-` id; PyPI a
  `LicenseRef-` expression, a License of Proprietary, Commercial or All rights reserved, or the
  Proprietary classifier. If it calls an open package closed, set a standard SPDX licence id.
- It runs in `pack` and the publish guard only, not in `scan` or the git push check.
