## What it finds

Extensions are what an AI agent loads as instructions or runs as its own tools: skills, slash
commands, subagents, rules and instruction files (`CLAUDE.md`, `AGENTS.md`, `GEMINI.md`, Cursor
and Windsurf rules, Kiro steering, ...), and installed plugins and extensions with their hooks
and scripts. Hook commands in agent settings are read too. AP010 prints four shapes:

- **Hidden characters** (high). Unicode tag characters, bidi overrides, bidi isolates in
  left-to-right text, deprecated format characters, and runs of zero-width characters or
  variation selectors: an AI reads them, a person reviewing the file sees nothing. A single
  stray zero-width character or direction mark is a low print: it hides no text.
- **Credential sent out** (critical). A credential's contents go into a command that sends data
  out: a key file piped into curl or nc, uploaded with curl's `-F` or `-T` or wget's
  `--post-file`, copied to another host with `scp`, or read into a variable and sent on a later
  line. In instructions, a sentence that tells the agent to read a credential location
  (`~/.ssh`, `~/.aws/credentials`, the macOS keychain, agent history, `.netrc`) and to send it,
  with a command or in plain words ("POST it to" a web address).
- **Piped download** (medium). A download run by a shell or interpreter that reads it, such as
  the output of `curl` or `wget` piped into `sh`, PowerShell's `irm` piped into `iex`, or a file
  downloaded and then run with no checksum. High when the text says to keep it from the user;
  low in a code block under an Install, Setup or Getting started heading.
- **Encoded command** (high). Base64 that decodes to a shell command, or a decode piped into a
  shell.

Each print names the file and line, and shows the command it matched with any key redacted.
For hidden characters it shows only how many of each kind there are.

## Why it matters

An agent follows its skills and rules without asking, and plugin hooks run with your
permissions. Hidden instructions, a skill that quietly uploads your SSH key, or an installer
that runs whatever a server returns today all reach your machine through a file that looks
harmless in a quick review.

## How to fix

1. Do not run or follow the flagged line. Ask yourself, or the person who added it, where the
   extension came from.
2. Remove the hidden characters or the encoded command. Install tools with a package manager
   at a pinned version instead of piping a download into a shell. Delete any instruction that
   sends credentials off the machine.
3. Remove an extension nobody added on purpose. If a credential may already have been sent,
   rotate it.

`agentprint fix` never edits an extension: every AP010 print is listed as yours, with the exact
file and line.

## Limits

- Each rule needs the risky shape, not a keyword. Not printed: a skill that mentions curl, a
  `.env` file loaded before an API call, a public key (`.pub`), `known_hosts`, ssh `config` or
  `authorized_keys`, a key named only as an option (`ssh -i <key>`, `--kubeconfig <file>`), a
  download piped into a script (`| bash scripts/x.sh`), and a sentence whose "never" or "do not"
  governs the command. Zero-width spaces in Thai, Lao, Khmer and Myanmar text, joiners in
  Hebrew, Arabic, Persian and Indic text, and bidi marks in right-to-left paragraphs are normal.
- Not read: `README`, `CHANGELOG`, `LICENSE` and similar files, `docs/`, `examples/` and
  `tests/` folders at an extension's top, dependency folders such as `node_modules`, and files
  over 2 MiB.
- One command line or one sentence at a time (a variable set from a credential is followed to
  later lines of the same script); minified code (lines over 8192 characters) is not read for
  shapes.
- Escaped characters (a `\u200b` written out in JSON) are not decoded.
- Each file has a reading budget that grows with its length, so text built to slow the scan
  down cannot. A file that spends it gets a low "not fully checked" print.
- Where each agent keeps its extensions comes from its docs; each agent module lists the paths
  and the pages they come from. Not read, because the docs name no folder: Claude Desktop's
  installed desktop extensions, a global Continue rules folder, the files Kilo Code's
  `instructions` setting points to, and Junie's skills and commands.
